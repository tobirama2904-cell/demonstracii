## 🎬 `видео/` — зрение на видео
`демо-фильм.mp4` — тестовый фильм из трёх сцен, который ассистент **посмотрел сам**:
кадры извлечены покадрово, рассмотрены по одному, склейки найдены на 5.96 и 11.96 сек
(при сценах ровно по 6 секунд). `таймлайн.jpg` — монтажная сетка всех кадров.

Кадры лежат рядом отдельными файлами — их ассистент разглядывал по одному и описал словами.

## 🗣 `голос/` — синтез речи

примерно в 11 раз быстрее реального времени.

## 👁 `зрение/` — распознавание текста
`тест-счёт.png` / `.pdf` — тестовый документ, текст с которого был распознан (OCR, рус+англ)
без единой ошибки, включая дату и сумму.
