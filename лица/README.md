# Распознавание лиц (YuNet)

Нейросетевой детектор находит портреты на фото и в видео с координатами и уверенностью.

- одиночный портрет → 1 лицо, уверенность 92–95%
- групповое фото из трёх человек → найдены все 3, позиции определены верно
- видео → по лицу в кадре, покадровый отчёт

`лица-*.jpg` — размеченные изображения, `отчёт.md` — таблица находок.
Все портреты в примерах — синтетические (сгенерированы), персональных данных нет.
