# Реставрация медиа
- `фото-до-и-после.png` — шумное размытое фото из «архива»: шумодав, резкость, автоуровни (слева — до, справа — после)
- `видео-кадр-до-и-после.png` и `видео-восстановлено.mp4` — дрожание, чересстрочность, шум, мутность
- `спектр-до-и-после.png` — звук: нейросетевой шумодав RNNoise + спектральный; шум в паузах тише в 26 раз, речь цела
Команды: `реставрация.py видео|звук|фото`, добавка `до-после` для сравнений.
