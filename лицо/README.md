# Говорящий портрет (Wav2Lip)
`говорящий-портрет.mp4` — лицо синхронизировано с речью послойно по кадрам (20 кадров/с на CPU).
Пайплайн: фото → поиск лица (YuNet) → рамка с запасом снизу → нейросеть Wav2Lip двигает губы под мел-спектрограмму речи → лёгкое дыхание кадра → H.264 + звук.
Проверено: 5.1 секунды речи за 6 секунд просчёта кадров (вся работа — 18 секунд).
