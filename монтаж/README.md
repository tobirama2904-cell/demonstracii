# Автомонтаж — фильм собран ассистентом целиком самостоятельно

`демо-автомонтаж.mp4` — 34 секунды: три кадра, озвученные моим синтезированным голосом,
субтитры вжигаются в кадр, длительность каждой сцены вычислена по реальной длине моей фразы.

Пайплайн: фразы → озвучка (Piper, русский голос) → измерение длительности каждой фразы →
кадры с эффектом медленного наплыва ровно под фразу → субтитры по таймингам → склейка в mp4.
`кадр-с-субтитрами.jpg` — как это выглядит, `*.srt` — файл субтитров.
