# Автомонтаж с живым голосом

`живой-голос-автомонтаж.mp4` — цифры "жизни" из старого демо заменены на живой русский голос (Silero).
Пайплайн: фразы → синтез выбранным движком (silero/kokoro/xtts/piper) → длительность каждой фразы
измеряется → кадры с наплывом ровно под фразу → субтитры по таймингам → mp4.
